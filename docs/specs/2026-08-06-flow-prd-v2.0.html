1Executive Summary / Ringkasan Eksekutif

Rebrand (2026-07-27): "Finance Hub" kini bernama FLOW (Financial Ledger and Operational Workspace). Produk, tujuan, dan tech stack tidak berubah — hanya nama & branding in-app. "Finance Hub" di spec/commit lama merujuk sistem yang sama.

FLOW adalah sistem manajemen keuangan internal berbasis web untuk Account Payable, Budget Monitoring, Sponsorship, Beasiswa, Bank, dan proses pembayaran, dijalankan secara lokal (localhost/LAN). Platform multi-perusahaan untuk dua entitas: Sinar Mas Tjipta (SMT) dan Eka Tjipta Foundation (ETF).

FLOW menggantikan sistem lama berbasis Excel VBA Macro (DbBeasiswa v2.2.xlsm), dan sejak v2.0 juga menggantikan spreadsheet manual untuk Budget Monitoring dan Sponsorship (rekap Excel "MR"/Rangkuman Sponsorship). Lihat Bagian 2.5.

Posisi dalam Masterplan Automasi PT Sinar Mas Tjipta

FLOW awalnya diposisikan sebagai Fase 4 (F4) — AP, Tax & Payment. Sejak v2.0, cakupannya melebar dan juga mencakup sebagian F1 (Budget & Master Data) — Budget Monitoring kini live di dalam FLOW, bukan lagi sistem terpisah.

2Problem Statement / Latar Belakang & Tujuan

2.1 Masalah Sebelumnya

Sebelum FLOW, pengelolaan keuangan dilakukan dengan file Excel manual di beberapa area:

  • Beasiswa: DbBeasiswa v2.2.xlsm (VBA Macro) di shared folder Y:/ — file lock conflict, tidak ada autentikasi/audit trail, PAM manual, PAM Recon PivotTable manual.
  • Budget Monitoring: Google Apps Script "Budget_Dashboard2" — laporan budget vs realisasi terpisah dari sistem transaksi, tidak ada carryover/additional budget workflow terstruktur.
  • Sponsorship: rekap Excel manual per pillar/description; format "MR" (Management Report) siap-upload GL disusun manual baris per baris termasuk nomor urut kode jurnal.
  • Bank Sahabat ETF: mutasi rekening internal pillar SETF dicatat manual, tidak tersinkron otomatis dengan status pembayaran PAM.
  • Data SMT dan ETF tidak terpisah secara sistematis di sistem-sistem lama tersebut.

2.2 Solusi

Item 1-12 dari v1.x tetap berlaku; tambahan v2.0 di bawah:

1-12. Fondasi v1.x

Portal terpusat, multi-company, JWT auth, PAM otomatis, Draft Memo, Days of PAM, dynamic badges, ETF PA, PAM Input Integration, REST API, export PDF/Excel, confirmation modal.

13. Budget Monitoring

Master, realisasi, carryover/additional workflow (request→approve/reject), dashboard budget-vs-realisasi per cost center (PO=SMT, TF=ETF).

14. Sponsorship (SMT)

Pencatatan sponsorship, dashboard BI, Outstanding, Rekap per pillar/description, format MR siap-upload GL (in progress).

15. Bank Sahabat ETF

Rekening internal pillar SETF, mutasi otomatis sinkron dari status PAM (complete→ledger) plus input manual, saldo berjalan.

16. Beasiswa Dashboard BI

Dashboard analitik: summary, breakdown kategori, tren bulanan, top pembayaran, per program & pillar.

17. Unified Navigation

Registry terpusat modul (DASHBOARD_TABS), command palette (Alt+K), module-switcher carousel (Alt+↓).

18. PAM untuk SMT

Vendors master data, tabel klasifikasi coa_pam untuk auto-mapping GL code, PAM lines Advance/Energy/Fiori.

→ INSERT budget_carryover_logs (type='Carryover', status='Pending')

→ INSERT budget_carryover_logs (type='Additional', status='Pending')

Releaser:

Konten: Summary per siswa, breakdown per kategori/pillar/tahun, monthly breakdown, latest payments (drill-down), family summary, export CSV Ringkasan/Detail + Excel Report tahunan.

Guard etf_company_required di setiap endpoint API/export (bukan cuma halaman).

API: /beasiswa/sahabat/api/summary, /breakdown, /monthly, /family_summary, /latest_payments, /detail/<siswa_code>, /export/summary, /export/detail, /export/report.
