# SPT Badan F1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modul SPT Badan tahap F1: periode SPT per entitas dan tahun, snapshot GL yang atomik, klasifikasi dan validasi berdasarkan Pemetaan, laporan laba rugi komersial YTD dengan drill-down ke baris GL, daftar pengecualian, dan ringkasan kontrol C1–C9.

**Architecture:** Paket baru `app/modules/spt_badan/`. Logika inti berupa fungsi murni tanpa database (`classify.py`, `income_statement.py`, `controls.py`), dibungkus `service.py` yang menyimpan snapshot dalam satu transaksi ke tabel `spt_*`, dan `routes.py` + template Jinja. GL dibaca dari modul General Ledger (multi-tahun); mapping dibaca dari `category_map` (Plan F0). Hasil berlabel "Simulasi YTD".

**Tech Stack:** Python 3 / Flask, SQLite (`database.get_conn`), openpyxl (ekspor pengecualian), Jinja2, pytest.

**Spec:** `docs/specs/2026-10-14-spt-badan-prd.md` (Bagian 14). **Prasyarat:** Plan `docs/superpowers/plans/2026-10-14-mr-pemetaan-kategori.md` sudah selesai (menyediakan `category_map` dan `gl_service.account_totals`).

## Global Constraints

- Entitas F1 hanya `smt` (konstanta `ENTITIES` di `service.py`); skema tidak boleh mengunci ke SMT saja.
- Snapshot disimpan paling banyak 3 per periode (`MAX_SNAPSHOTS = 3`); hanya satu `is_current = 1`.
- Snapshot ditulis dalam satu transaksi; kegagalan tidak boleh meninggalkan snapshot setengah jadi atau mengubah snapshot aktif sebelumnya.
- Toleransi uang untuk kontrol C1 dan C6: Rp1; kontrol hitungan: 0.
- Jenis PPh baku: `PPh 21`, `PPh 23`, `PPh 4(2)`, `Non PPh` (dari `category_map.PPH_TYPES`).
- Pendapatan ditampilkan positif (−`debit_credit`), beban positif (+`debit_credit`), kategori sifat `lainnya` ditampilkan sebagai pendapatan positif (−`debit_credit`).
- Setiap halaman SPT menampilkan label periode (`Simulasi YTD`) dan rentang tanggal snapshot.
- Buat periode, ambil snapshot, dan semua POST hanya admin (`json_admin_required`); halaman GET untuk semua pengguna login (`jwt_html_required`).
- Pesan antarmuka berbahasa Indonesia; kode, nama tabel, dan komentar berbahasa Inggris.
- Tidak mengubah tabel `GLSMT/GLETF/GLSETF` dan tidak menulis ke `finance_hub.db` saat test (fixture `clean_db`).

## Review Focus

- Snapshot gagal di tengah → snapshot aktif sebelumnya tetap utuh (Task 4).
- GL tahun itu kosong atau akun tanpa pemetaan → pesan jelas, kontrol C3 gagal, tidak crash (Task 4).
- Mapping atau GL berubah setelah snapshot → banner usang dan C8 peringatan (Task 4–5).
- Total drill-down sama persis dengan angka di laporan, termasuk baris tanpa Category SPT (Task 4–5).
- Pengecualian PPh jumlahnya ribuan → halaman tetap cepat dan terkelompok per akun (Task 4–5).
- Non-admin tidak dapat membuat periode atau snapshot (Task 5).

# modules/spt_badan/classify.py
"""SPT Badan: classify one GL line against the Pemetaan (pure functions, no database)."""
from modules.management_report.category_map import alias_key, is_unmapped

BLOCKER = "blocker"
WARNING = "warning"
PPH_KINDS = ("pph_kosong", "pph_bukan_jenis")


def _exc(kind, severity, detail):
    return {"kind": kind, "severity": severity, "detail": detail}


def _norm(value) -> str:
    return str(value or "").strip().lower()


def classify_pph(raw, is_expense, aliases):
    """Return (pph_type, exception_kind); exception_kind is '' when the value is fine."""
    key = alias_key(raw)
    if key:
        pph_type = aliases.get(key, "")
        return (pph_type, "") if pph_type else ("", "pph_bukan_jenis")
    return ("", "pph_kosong" if is_expense else "")


def classify_line(line, source, cmap, lk_list, aliases):
    """Classify a GL line. Returns (classified_line, exceptions).

    Category LK / SPT come from the Pemetaan; the values carried by the GL row are only compared."""
    account = str(line["acc_statutory"] or "")
    entry = cmap.get((source, account))
    lk = spt = ""
    meta = None
    exceptions = []
    if entry is None:
        exceptions.append(_exc("akun_belum_dipetakan", BLOCKER,
                               f"Akun {account} tidak ada di pemetaan kategori"))
    elif is_unmapped(entry["category_lk"]):
        exceptions.append(_exc("akun_belum_dipetakan", BLOCKER,
                               f"Category LK akun {account} kosong / TBA"))
    else:
        lk = entry["category_lk"]
        spt = "" if is_unmapped(entry["category_spt"]) else entry["category_spt"]
        meta = lk_list.get(lk)
        if meta is None or not meta["statement"]:
            exceptions.append(_exc("category_lk_tidak_dikenal", BLOCKER,
                                   f"Category LK '{lk}' belum diatur jenis laporannya"))
            meta = None
        elif meta["needs_spt"] and not spt:
            exceptions.append(_exc("category_spt_kosong", BLOCKER,
                                   f"Category SPT akun {account} kosong / TBA"))
        if (_norm(line.get("category_lk")) != _norm(entry["category_lk"])
                or _norm(line.get("category_spt")) != _norm(entry["category_spt"])):
            exceptions.append(_exc(
                "kategori_gl_beda", WARNING,
                f"GL: {line.get('category_lk') or '-'} / {line.get('category_spt') or '-'}; "
                f"pemetaan: {entry['category_lk'] or '-'} / {entry['category_spt'] or '-'}"))

    raw = str(line.get("pph_non_pph") or "").strip()
    pph_type, pph_kind = classify_pph(raw, bool(meta and meta["needs_spt"]), aliases)
    if pph_kind:
        detail = "Jenis PPh kosong pada baris biaya" if pph_kind == "pph_kosong" \
            else f"'{raw}' bukan jenis PPh"
        exceptions.append(_exc(pph_kind, WARNING, detail))

    classified = {
        "gl_id": line["id"], "tgl": line["tgl"], "id_no": line["id_no"],
        "acc_statutory": account, "acc_management": line["acc_management"],
        "job_name": line["job_name"], "memo": line["memo"], "debit_credit": line["debit_credit"],
        "accrual_actual": line["accrual_actual"], "category_lk": lk, "category_spt": spt,
        "pph_type_raw": raw, "pph_type": pph_type,
    }
    return classified, exceptions
```

# modules/spt_badan/income_statement.py
"""SPT Badan: commercial income statement from classified lines (pure functions)."""
HPP = "HARGA POKOK PENJUALAN"
OPEX = "Beban Operasional"
TAX = "Income Tax Expense"
NO_SPT_LABEL = "(tanpa Category SPT)"


def aggregate(lines):
    """Net debit_credit per Category LK and per (Category LK, Category SPT); unclassified lines are skipped."""
    totals, spt_totals = {}, {}
    for line in lines:
        lk = line["category_lk"]
        if not lk:
            continue
        amount = line["debit_credit"] or 0.0
        totals[lk] = totals.get(lk, 0.0) + amount
        key = (lk, line["category_spt"] or "")
        spt_totals[key] = spt_totals.get(key, 0.0) + amount
    return totals, spt_totals


def _row(key, label, amount, kind, cats=None, spt=None):
    return {"key": key, "label": label, "amount": amount, "kind": kind, "cats": cats, "spt": spt}


def _sub_rows(prefix, cats, spt_totals, sign):
    by_spt = {}
    for (lk, spt), value in spt_totals.items():
        if lk in cats:
            by_spt[spt] = by_spt.get(spt, 0.0) + sign * value
    return [_row(f"{prefix}:{spt}", spt or NO_SPT_LABEL, amount, "sub", list(cats), spt)
            for spt, amount in sorted(by_spt.items(), key=lambda kv: (-kv[1], kv[0]))]


def build_income_statement(totals, spt_totals, lk_list):
    pnl = {name: meta for name, meta in lk_list.items() if meta["statement"] == "laba_rugi"}
    net = lambda names: sum(totals.get(n, 0.0) for n in names)           # noqa: E731
    revenue_cats = [n for n, m in pnl.items() if m["kind"] == "pendapatan"]
    opex_cats = [n for n, m in pnl.items() if m["kind"] == "beban" and n not in (HPP, TAX)]
    other_cats = [n for n, m in pnl.items() if m["kind"] == "lainnya"]
    hpp_cats = [HPP] if HPP in pnl else []
    tax_cats = [TAX] if TAX in pnl else []

    revenue = -net(revenue_cats)
    hpp = net(hpp_cats)
    gross = revenue - hpp
    opex = net(opex_cats)
    operating = gross - opex
    other_rows = [(n, -totals.get(n, 0.0)) for n in other_cats]
    other = sum(v for _, v in other_rows)
    pbt = operating + other
    tax = net(tax_cats)

    rows = [_row("revenue", "Pendapatan bersih", revenue, "item", revenue_cats),
            _row("hpp", "Harga pokok penjualan", hpp, "item", hpp_cats),
            *_sub_rows("hpp", hpp_cats, spt_totals, 1),
            _row("gross", "Laba kotor", gross, "subtotal"),
            _row("opex", "Biaya operasional", opex, "item", opex_cats),
            *_sub_rows("opex", opex_cats, spt_totals, 1),
            _row("operating", "Laba operasional", operating, "subtotal")]
    for name, value in other_rows:
        rows.append(_row(f"other:{name}", pnl[name]["label"] or name, value, "item", [name]))
        rows.extend(_sub_rows(f"other:{name}", [name], spt_totals, -1))
    rows += [_row("pbt", "Laba sebelum pajak penghasilan", pbt, "subtotal"),
             _row("tax", "Income tax expense", tax, "item", tax_cats),
             _row("net", "Laba (rugi) bersih", pbt - tax, "subtotal")]
    summary = {"revenue": revenue, "hpp": hpp, "gross": gross, "opex": opex, "operating": operating,
               "other": other, "pbt": pbt, "tax": tax, "net": pbt - tax}
    return {"rows": rows, "summary": summary}

"""SPT Badan: control checks C1-C9 (pure functions)."""
from modules.spt_badan.classify import PPH_KINDS

TOL_MONEY = 1.0


def _control(code, name, left, right, blocking, tol=0.0):
    diff = left - right
    if abs(diff) <= tol:
        status = "lulus"
    else:
        status = "gagal" if blocking else "peringatan"
    return {"code": code, "name": name, "left_value": left, "right_value": right,
            "diff": diff, "status": status, "blocking": 1 if blocking else 0}


def _count(exceptions, kinds):
    return sum(1 for e in exceptions if e["kind"] in kinds)


def compute_controls(*, total_debit, total_credit, line_count, gl_row_count, exceptions, out_of_year,
                     statement_pbt, pnl_sum_excl_tax):
    return [
        _control("C1", "Total debit = total kredit", total_debit, total_credit, True, TOL_MONEY),
        _control("C2", "Jumlah baris snapshot = jumlah baris GL", line_count, gl_row_count, True),
        _control("C3", "Semua akun terpetakan dan Category LK dikenal",
                 _count(exceptions, ("akun_belum_dipetakan", "category_lk_tidak_dikenal")), 0, True),
        _control("C4", "Semua baris HPP/biaya punya Category SPT",
                 _count(exceptions, ("category_spt_kosong",)), 0, True),
        _control("C5", "Semua tanggal berada di tahun pajak", out_of_year, 0, True),
        _control("C6", "Laba sebelum pajak = jumlah baris laba rugi di GL",
                 statement_pbt, pnl_sum_excl_tax, True, TOL_MONEY),
        _control("C7", "Jenis PPh bersih (tanpa kosong / bukan jenis)",
                 _count(exceptions, PPH_KINDS), 0, False),
        _control("C9", "Kategori pada baris GL = hasil Pemetaan",

import json
import sqlite3
from datetime import datetime

from database import get_conn

ENTITIES = {"smt": {"label": "SMT", "source": "SMT"}}
MAX_SNAPSHOTS = 3
MIN_YEAR, MAX_YEAR = 2000, 2100

_DDL = """
CREATE TABLE IF NOT EXISTS spt_period (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    entity     TEXT NOT NULL,
    tax_year   INTEGER NOT NULL,
    status     TEXT NOT NULL DEFAULT 'draft',
    label      TEXT NOT NULL DEFAULT '',
    params     TEXT NOT NULL DEFAULT '{}',
    created_at TEXT,
    created_by TEXT,
    UNIQUE (entity, tax_year)
);
CREATE TABLE IF NOT EXISTS spt_snapshot (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    period_id     INTEGER NOT NULL REFERENCES spt_period(id),
    taken_at      TEXT,
    taken_by      TEXT,
    gl_hash       TEXT NOT NULL DEFAULT '',
    map_version   INTEGER NOT NULL DEFAULT 0,
    row_count     INTEGER NOT NULL DEFAULT 0,
    total_debit   REAL NOT NULL DEFAULT 0,
    total_credit  REAL NOT NULL DEFAULT 0,
    date_min      TEXT,
    date_max      TEXT,
    is_current    INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_spt_snapshot_period ON spt_snapshot(period_id, is_current);
CREATE TABLE IF NOT EXISTS spt_gl_line (
    snapshot_id    INTEGER NOT NULL,
    gl_id          INTEGER NOT NULL,
    tgl            TEXT,
    id_no          TEXT,
    acc_statutory  TEXT,
    acc_management TEXT,
    job_name       TEXT,
    memo           TEXT,
    debit_credit   REAL,
    category_lk    TEXT,
    category_spt   TEXT,
    pph_type_raw   TEXT,
    pph_type       TEXT,
    accrual_actual TEXT,
    PRIMARY KEY (snapshot_id, gl_id)
);
CREATE INDEX IF NOT EXISTS idx_spt_line_cat ON spt_gl_line(snapshot_id, category_lk, category_spt);
CREATE TABLE IF NOT EXISTS spt_exception (
    snapshot_id INTEGER NOT NULL,
    gl_id       INTEGER NOT NULL,
    kind        TEXT NOT NULL,
    severity    TEXT NOT NULL,
    account     TEXT,
    detail      TEXT
);
CREATE INDEX IF NOT EXISTS idx_spt_exc_snapshot ON spt_exception(snapshot_id, kind);
CREATE TABLE IF NOT EXISTS spt_control (
    snapshot_id INTEGER NOT NULL,
    code        TEXT NOT NULL,
    name        TEXT NOT NULL,
    left_value  REAL,
    right_value REAL,
    diff        REAL,
    status      TEXT NOT NULL,
    blocking    INTEGER NOT NULL DEFAULT 0,
    PRIMARY KEY (snapshot_id, code)
);
"""


def ensure_schema(conn) -> None:
    conn.executescript(_DDL)
    conn.commit()


def _ts() -> str:
    return datetime.now().isoformat(timespec="seconds")


def create_period(entity, tax_year, user, label="Simulasi YTD", params=None) -> int:
    if entity not in ENTITIES:
        raise ValueError("Entitas belum didukung.")
    try:
        year = int(tax_year)
    except (TypeError, ValueError):
        raise ValueError(f"Tahun pajak harus berupa angka {MIN_YEAR}-{MAX_YEAR}.") from None
    if not MIN_YEAR <= year <= MAX_YEAR:
        raise ValueError(f"Tahun pajak harus antara {MIN_YEAR} dan {MAX_YEAR}.")
    conn = get_conn()
    try:
        ensure_schema(conn)
        try:
            cur = conn.execute(
                "INSERT INTO spt_period (entity, tax_year, status, label, params, created_at, created_by) "
                "VALUES (?,?,?,?,?,?,?)",
                (entity, year, "draft", (label or "").strip(), json.dumps(params or {}, ensure_ascii=False),
                 _ts(), user))
            conn.commit()
        except sqlite3.IntegrityError:
            conn.rollback()
            raise ValueError(f"Periode {ENTITIES[entity]['label']} {year} sudah ada.") from None
        return cur.lastrowid
    finally:
        conn.close()


def _period_row(r):
    d = dict(r)
    d["params"] = json.loads(d["params"]) if d.get("params") else {}
    return d


def get_period(period_id):
    conn = get_conn()
    try:
        ensure_schema(conn)
        row = conn.execute("SELECT * FROM spt_period WHERE id=?", (period_id,)).fetchone()
        return _period_row(row) if row else None
    finally:
        conn.close()


def list_periods() -> list:
    conn = get_conn()
    try:
        ensure_schema(conn)
        return [_period_row(r) for r in conn.execute(
            "SELECT * FROM spt_period ORDER BY tax_year DESC, entity")]
    finally:
        conn.close()
```

def _prune(conn, period_id) -> None:
    old = [r[0] for r in conn.execute(
        "SELECT id FROM spt_snapshot WHERE period_id=? ORDER BY id DESC LIMIT -1 OFFSET ?",
        (period_id, MAX_SNAPSHOTS))]
    for sid in old:
        for table in ("spt_gl_line", "spt_exception", "spt_control"):
            conn.execute(f"DELETE FROM {table} WHERE snapshot_id=?", (sid,))
        conn.execute("DELETE FROM spt_snapshot WHERE id=?", (sid,))


def take_snapshot(period_id, user) -> int:
    """Classify the period's GL year and store it all in one transaction; returns the snapshot id."""
    period = get_period(period_id)
    if period is None:
        raise KeyError(period_id)
    entity, year = period["entity"], period["tax_year"]
    ent = ENTITIES[entity]
    gl_lines = gl_service.load_lines(entity, year)
    if not gl_lines:
        raise ValueError(f"Tidak ada baris GL {ent['label']} untuk tahun {year}. Sync General Ledger dulu.")

    cmap = category_map.get_category_map()
    lk_list = category_map.get_lk_list()
    aliases = category_map.get_pph_aliases()
    map_version = category_map.get_version()
    last = gl_service.last_sync(entity, year)
    gl_hash = last["content_hash"] if last else ""

    classified, exceptions = [], []
    for line in gl_lines:
        item, found = classify.classify_line(line, ent["source"], cmap, lk_list, aliases)
        classified.append(item)
        exceptions.extend({**e, "gl_id": item["gl_id"], "account": item["acc_statutory"]} for e in found)

    totals, spt_totals = income_statement.aggregate(classified)
    statement = income_statement.build_income_statement(totals, spt_totals, lk_list)
    pnl = {n for n, m in lk_list.items() if m["statement"] == "laba_rugi"}
    pnl_sum = -sum(v for n, v in totals.items() if n in pnl and n != income_statement.TAX)
    total_debit = sum(l["debit"] or 0.0 for l in gl_lines)
    total_credit = sum(l["credit"] or 0.0 for l in gl_lines)
    computed = controls.compute_controls(
        total_debit=total_debit, total_credit=total_credit, line_count=len(classified),
        gl_row_count=gl_service.row_count(entity, year), exceptions=exceptions,
        out_of_year=sum(1 for l in classified if not (l["tgl"] or "").startswith(f"{year}-")),
        statement_pbt=statement["summary"]["pbt"], pnl_sum_excl_tax=pnl_sum)
    dates = sorted(l["tgl"] for l in classified if l["tgl"])

    conn = get_conn()
    try:
        ensure_schema(conn)
        try:
            conn.execute("UPDATE spt_snapshot SET is_current=0 WHERE period_id=?", (period_id,))
            cur = conn.execute(
                "INSERT INTO spt_snapshot (period_id, taken_at, taken_by, gl_hash, map_version, row_count, "
                "total_debit, total_credit, date_min, date_max, is_current) VALUES (?,?,?,?,?,?,?,?,?,?,1)",
                (period_id, _ts(), user, gl_hash, map_version, len(classified), total_debit, total_credit,
                 dates[0] if dates else None, dates[-1] if dates else None))
            sid = cur.lastrowid
            conn.executemany(
                "INSERT INTO spt_gl_line (snapshot_id, gl_id, tgl, id_no, acc_statutory, acc_management, "
                "job_name, memo, debit_credit, category_lk, category_spt, pph_type_raw, pph_type, "
                "accrual_actual) VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)",
                [(sid, l["gl_id"], l["tgl"], l["id_no"], l["acc_statutory"], l["acc_management"],
                  l["job_name"], l["memo"], l["debit_credit"], l["category_lk"], l["category_spt"],
                  l["pph_type_raw"], l["pph_type"], l["accrual_actual"]) for l in classified])
            conn.executemany(
                "INSERT INTO spt_exception (snapshot_id, gl_id, kind, severity, account, detail) "
                "VALUES (?,?,?,?,?,?)",
                [(sid, e["gl_id"], e["kind"], e["severity"], e["account"], e["detail"]) for e in exceptions])
            conn.executemany(
                "INSERT INTO spt_control (snapshot_id, code, name, left_value, right_value, diff, status, "
                "blocking) VALUES (?,?,?,?,?,?,?,?)",
                [(sid, c["code"], c["name"], c["left_value"], c["right_value"], c["diff"], c["status"],
                  c["blocking"]) for c in computed])
            _prune(conn, period_id)
            conn.commit()
        except Exception:
            conn.rollback()
            raise
    finally:
        conn.close()
    return sid

def staleness(period, snapshot) -> list:
    reasons = []
    last = gl_service.last_sync(period["entity"], period["tax_year"])
    if snapshot["gl_hash"] != (last["content_hash"] if last else ""):
        reasons.append("GL berubah sejak snapshot")
    if snapshot["map_version"] != category_map.get_version():
        reasons.append("Pemetaan berubah sejak snapshot")
    return reasons


def get_controls(period, snapshot) -> list:
    conn = get_conn()
    try:
        ensure_schema(conn)
        stored = [dict(r) for r in conn.execute(
            "SELECT * FROM spt_control WHERE snapshot_id=?", (snapshot["id"],))]
    finally:
        conn.close()
    stored.append(controls.stale_control(staleness(period, snapshot)))
    return sorted(stored, key=lambda c: c["code"])


def step_statuses(snapshot, ctrls) -> list:
    if snapshot is None:
        return [{"name": n, "status": "belum", "endpoint": e} for n, e in (
            ("Snapshot GL", "spt_badan.detail"), ("Validasi klasifikasi", "spt_badan.exceptions"),
            ("Laba rugi komersial", "spt_badan.income_statement"), ("Kontrol", "spt_badan.controls_page"))]
    by = {c["code"]: c for c in ctrls}

    def worst(*codes):
        sts = [by[c]["status"] for c in codes if c in by]
        return "gagal" if "gagal" in sts else "peringatan" if "peringatan" in sts else "lulus"

    return [
        {"name": "Snapshot GL", "status": worst("C1", "C2", "C5"), "endpoint": "spt_badan.detail"},
        {"name": "Validasi klasifikasi", "status": worst("C3", "C4", "C7", "C9"),
         "endpoint": "spt_badan.exceptions"},
        {"name": "Laba rugi komersial", "status": worst("C6"), "endpoint": "spt_badan.income_statement"},
        {"name": "Kontrol", "status": worst(*by), "endpoint": "spt_badan.controls_page"},
    ]

def _like(text) -> str:
    esc = text.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")
    return f"%{esc}%"


def _paged(total, page, per_page):
    pages = max(1, -(-total // per_page))
    page = min(max(1, page), pages)
    return page, pages, (page - 1) * per_page


def exception_groups(snapshot_id) -> list:
    conn = get_conn()
    try:
        ensure_schema(conn)
        return [dict(r) for r in conn.execute(
            "SELECT kind, severity, account, COUNT(*) AS n FROM spt_exception WHERE snapshot_id=? "
            "GROUP BY kind, severity, account "
            "ORDER BY CASE severity WHEN 'blocker' THEN 0 ELSE 1 END, n DESC, kind, account",
            (snapshot_id,))]
    finally:
        conn.close()


def list_exceptions(snapshot_id, kind="", severity="", q="", page=1, per_page=100) -> dict:
    clauses, params = ["e.snapshot_id = ?"], [snapshot_id]
    if kind:
        clauses.append("e.kind = ?"); params.append(kind)
    if severity:
        clauses.append("e.severity = ?"); params.append(severity)
    if q:
        clauses.append("(e.account LIKE ? ESCAPE '\\' OR l.memo LIKE ? ESCAPE '\\' OR l.id_no LIKE ? ESCAPE '\\' "
                       "OR l.job_name LIKE ? ESCAPE '\\' OR e.detail LIKE ? ESCAPE '\\')")
        params += [_like(q)] * 5
    where = " AND ".join(clauses)
    base = ("FROM spt_exception e LEFT JOIN spt_gl_line l "
            "ON l.snapshot_id = e.snapshot_id AND l.gl_id = e.gl_id WHERE " + where)
    conn = get_conn()
    try:
        ensure_schema(conn)
        total = conn.execute(f"SELECT COUNT(*) {base}", params).fetchone()[0]
        page, pages, offset = _paged(total, page, per_page)
        rows = [dict(r) for r in conn.execute(
            f"SELECT e.kind, e.severity, e.detail, e.account, l.tgl, l.id_no, l.job_name, l.memo, "
            f"l.debit_credit, l.pph_type_raw {base} "
            f"ORDER BY CASE e.severity WHEN 'blocker' THEN 0 ELSE 1 END, e.kind, e.account, l.tgl "
            f"LIMIT ? OFFSET ?", params + [per_page, offset])]
    finally:
        conn.close()
    return {"rows": rows, "total": total, "page": page, "pages": pages, "per_page": per_page}


def drill_lines(snapshot_id, cats, spt=None, page=1, per_page=100) -> dict:
    """GL lines behind one statement row: lines of `cats`, and of Category SPT `spt` when it is not None."""
    cats = list(cats or [])
    if not cats:
        return {"rows": [], "total": 0, "amount": 0.0, "page": 1, "pages": 1, "per_page": per_page}
    clauses = ["snapshot_id = ?", "category_lk IN (" + ",".join("?" * len(cats)) + ")"]
    params = [snapshot_id, *cats]
    if spt is not None:
        clauses.append("category_spt = ?"); params.append(spt)
    where = " AND ".join(clauses)
    conn = get_conn()
    try:
        ensure_schema(conn)
        total, amount = conn.execute(
            f"SELECT COUNT(*), COALESCE(SUM(debit_credit), 0) FROM spt_gl_line WHERE {where}", params).fetchone()
        page, pages, offset = _paged(total, page, per_page)
        rows = [dict(r) for r in conn.execute(
            f"SELECT tgl, id_no, acc_statutory, acc_management, job_name, memo, debit_credit, category_lk, "
            f"category_spt, pph_type FROM spt_gl_line WHERE {where} ORDER BY tgl, gl_id LIMIT ? OFFSET ?",
            params + [per_page, offset])]
    finally:
        conn.close()
    return {"rows": rows, "total": total, "amount": amount, "page": page, "pages": pages,
            "per_page": per_page}

import io
from urllib.parse import urlencode

from flask import Blueprint, abort, jsonify, render_template, request, send_file, session
from flask_jwt_extended import get_jwt

from auth.middleware import is_admin, json_admin_required, jwt_html_required
from modules.spt_badan import service

bp = Blueprint("spt_badan", __name__, url_prefix="/spt-badan")

KIND_LABELS = {
    "akun_belum_dipetakan": "Akun belum dipetakan", "category_lk_tidak_dikenal": "Category LK belum diatur",
    "category_spt_kosong": "Category SPT kosong", "pph_kosong": "Jenis PPh kosong",
    "pph_bukan_jenis": "Bukan jenis PPh", "kategori_gl_beda": "Kategori GL ≠ Pemetaan",
}


def _spt_num(value) -> str:
    """1234567.4 -> '1.234.567' (Indonesian thousands separator); None -> ''."""
    if value is None:
        return ""
    return f"{float(value):,.0f}".replace(",", ".")


bp.add_app_template_filter(_spt_num, "spt_num")


def _ctx():
    try:
        claims = get_jwt()
        return {"current_user": claims.get("username", ""), "current_role": claims.get("role", ""),
                "can_manage": is_admin(claims), "company_id": session.get("company_id"),
                "company_code": session.get("company_code"), "company_name": session.get("company_name")}
    except Exception:
        return {}


def _page():
    try:
        return max(1, int(request.args.get("page", 1)))
    except (TypeError, ValueError):
        return 1


def _period_or_404(pid):
    period = service.get_period(pid)
    if period is None:
        abort(404)
    return period


def _render(template, period, **extra):
    snapshot = service.get_current_snapshot(period["id"])
    stale = service.staleness(period, snapshot) if snapshot else []
    return render_template(
        template, period=period, snapshot=snapshot, stale=stale, entity_label=service.ENTITIES[period["entity"]]["label"],
        kind_labels=KIND_LABELS, active_page="spt_badan", use_unified_header=True, **_ctx(), **extra)


@bp.route("/")
@jwt_html_required
def index():
    periods = []
    for p in service.list_periods():
        snap = service.get_current_snapshot(p["id"])
        periods.append({**p, "snapshot": snap, "stale": bool(snap and service.staleness(p, snap)),
                        "entity_label": service.ENTITIES[p["entity"]]["label"]})
    return render_template("spt_badan/index.html", periods=periods, entities=service.ENTITIES,
                           active_page="spt_badan", use_unified_header=True, **_ctx())


@bp.route("/periods", methods=["POST"])
@json_admin_required
def create_period():
    d = request.get_json(silent=True) or {}
    try:
        pid = service.create_period(d.get("entity", ""), d.get("tax_year"), get_jwt().get("username", ""),
                                    label=d.get("label") or "Simulasi YTD")
    except ValueError as e:
        return jsonify({"ok": False, "pesan": str(e)}), 400
    return jsonify({"ok": True, "id": pid, "pesan": "Periode dibuat."})


@bp.route("/<int:pid>")
@jwt_html_required
def detail(pid):
    period = _period_or_404(pid)
    snapshot = service.get_current_snapshot(pid)
    ctrls = service.get_controls(period, snapshot) if snapshot else []
    summary = service.income_statement_for(snapshot["id"])["summary"] if snapshot else None
    blockers = sum(1 for c in ctrls if c["status"] == "gagal")
    return _render("spt_badan/detail.html", period, active_tab="detail", steps=service.step_statuses(snapshot, ctrls),
                   summary=summary, blockers=blockers, controls=ctrls)


@bp.route("/<int:pid>/snapshot", methods=["POST"])
@json_admin_required
def snapshot(pid):
    period = service.get_period(pid)
    if period is None:
        return jsonify({"ok": False, "pesan": "Periode tidak ditemukan."}), 404
    try:
        sid = service.take_snapshot(pid, get_jwt().get("username", ""))
    except ValueError as e:
        return jsonify({"ok": False, "pesan": str(e)}), 400
    except Exception as e:
        return jsonify({"ok": False, "pesan": f"Snapshot gagal, snapshot sebelumnya tidak berubah: {e}"}), 500
    snap = service.get_current_snapshot(pid)
    blockers = sum(1 for c in service.get_controls(period, snap) if c["status"] == "gagal")
    pesan = f"Snapshot selesai: {snap['row_count']} baris GL; {blockers} kontrol wajib gagal."
    return jsonify({"ok": True, "pesan": pesan, "snapshot_id": sid, "blockers": blockers})

@jwt_html_required

    kind = request.args.get("kind") if request.args.get("kind") in KIND_LABELS else ""
    severity = request.args.get("severity") if request.args.get("severity") in ("blocker", "warning") else ""
    q = (request.args.get("q") or "").strip()
    data = groups = None
    if snapshot:
        groups = service.exception_groups(snapshot["id"])
        data = service.list_exceptions(snapshot["id"], kind, severity, q, page=_page())
    return _render("spt_badan/pengecualian.html", period, active_tab="pengecualian", groups=groups, data=data,
                   kind=kind, severity=severity, q=q)

    buf.seek(0)
    return send_file(buf, as_attachment=True,
                     download_name=f"pengecualian-spt-{period['entity']}-{period['tax_year']}.xlsx",
                     mimetype="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet")
